## 主页布局交互简化：去除编辑模式，改为鼠标拖拽排序（Lucky 要求）
前一日已落地「编辑模式 + 前/后移按钮 + resize 缩放柄 + 编辑/重置/完成按钮」的卡片自由布局。Lucky 要求简化：去除按钮调整、去除编辑/完成按钮，改用鼠标直接拖动卡片排序，并参考网站管理卡片（SiteCard）逻辑。

**改动**
- `useHomeLayout.ts`：删除 `editMode`/`resizing`/`moveCard`/`startResize`/`resetCard`/`resetAll`/`hasCustom`；新增 `dragSourceId`/`dragOverId` 两个 ref 与 `handleDragStart/Over/Leave/Drop/End`（原生 HTML5 DnD）+ `reorderCard(from,to)`（同容器内交换两卡 `o` 值，跨容器忽略）。逻辑对齐 `HomeView.vue` 的 `swapSort`。
- `HomeLayoutCard.vue`：去掉编辑态门控与 `HomeCardEdit`/`HomeCardResize` 注入；卡片常驻 `draggable="true"`，直接挂 5 个拖拽事件；`is-dragging`/`is-drag-over` 高亮（虚线主色描边）。`cardStyle` 仍应用 `w/h/o`（向后兼容已存布局）。
- 删除 `HomeCardEdit.vue` / `HomeCardResize.vue`（不再使用）。
- `WorkbenchHome.vue`：问候条删除「编辑布局/重置布局/完成」三按钮（含 `.greeting-actions`/`.layout-toggle` 样式与暗色覆盖）；`navTo` 去掉 `editMode` 拦截（点击与拖拽不冲突：拖拽走 DnD、点击才跳转）；移除 `useHomeLayout` 引入与 editMode/hasCustom 相关变量。

**踩坑**：模板里 `layout.dragSourceId === cardId` 报 `TS2367`（Ref 与 string 无交集）。原因：通过普通对象属性 `layout.xxx` 访问的 ref **不会被模板自动拆包**（仅 `<script setup>` 顶层 ref 才拆包）；旧代码用 `const editMode = layout.editMode` 取顶层 ref 才正常。修法：在 `HomeLayoutCard` 里 `const { dragSourceId, dragOverId, ... } = useHomeLayout()` 解构成顶层绑定，模板即可正确比较。

**验证**：`vue-tsc -b` EXIT=0；`vite build` EXIT=0。`presetIcons.ts` 仅时间戳变动，提交前 `git checkout --` 还原（惯例）。
