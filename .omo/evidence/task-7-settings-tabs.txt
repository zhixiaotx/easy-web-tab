GOTCHA (see learnings.md): initSettings MERGES into existing in-memory state — it only
overrides entries present in the loaded IDB record. Empty stored settings do NOT reset
a size previously set in the same session (e.g. after setDialogSize(700)). The failure
path's "defaults" assertion therefore only holds on a fresh page load; run failure QA
after a reload, not right after the happy-path size change.
