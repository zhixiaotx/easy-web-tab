## P1 遗留实施：移动端弹窗全屏化（新增 mobile.css，未提交）
- 调研结论（Explore agent）：手写弹窗全在 scoped 内（AppSettingsDialog/CountdownModal/CategoryManager/IconManager/SearchEngineManager 用 `.manager-overlay+.manager`；SiteModal `.modal-overlay+.modal`；HelpModal `.help-modal`；BackgroundManager；BackupManager；工作台各面板 `.dialog-overlay+.dialog`；WorkbenchNotes `.note-overlay`；WorkbenchPassword `.pwd-modal-*`）；**el-dialog 共 24 个文件使用**，且 `.el-dialog` 不带 data-v，全局规则可一次命中。此前所谓"适配"只是 `max-height:90vh`（AppSettingsDialog:2935 / CountdownModal:389 / HelpModal:1279），**无真正全屏**。无统一弹窗组件。element-theme.css 仅 28 行、只定义 --el-* 色变量，无 dialog 覆盖。
- 方案：**新增 `src/styles/mobile.css`**（main.ts 引入，在 style.css/background.css 之后），`@media (max-width:767px)`：
  1. 9 个 overlay 类名（名单复用 animations.css:86-94）+ `.el-overlay` → `padding:0 !important`。
  2. 手写弹窗卡片 → 用「**遮罩层 > 直接子元素**」选择器全屏化（`width/height/max-height:100%; border-radius:0; overflow-y:auto`）。**不枚举碎片卡片类名**，故不误伤弹窗外同名元素；保留 overflow-y:auto 确保内部结构不支持 flex 收缩时内容也不被裁切。必须用 `!important` 才能压过 scoped 的 `[data-v-xxx]`。
  3. `.el-dialog` → 全屏 + `display:flex; flex-direction:column; overflow:hidden`；`.el-dialog__body{flex:1; min-height:0; overflow-y:auto}` 固定头尾、body 独立滚动。
