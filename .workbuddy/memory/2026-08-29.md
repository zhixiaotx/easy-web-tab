### 做法要点（可复用）
- **权威 path 来源**：`npm install @mdi/js` 装到托管 node workspace（`~/.workbuddy/binaries/node/workspace`），用 ESM 脚本提取 `mdiXxx` 的 24×24 path 字面量，再写进 `src/components/Icon.vue`。**不引入项目依赖**，且 path 100% 准确（不靠记忆瞎写）。
- **安全设计（关键）**：批量替换脚本**只改 `</script>` 之后的模板区，不碰 script 区**，避免把 `<Icon>` 组件标签塞进 JS 字符串/数据数组（如 Toast 的 icons 映射、SiteModal 的错误提示串、HelpModal 的 features 数组）导致渲染成字面文本。
- 脚本自动为用到 `<Icon>` 但缺少 import 的文件补 `import Icon from '<相对路径>/Icon.vue'`（components/→`./`，business·workbench/→`../`，views/→`../components/`）。若该文件已有 import（如 WorkbenchSleep 用 `@/components/Icon.vue` 别名）则跳过，不重复添加。
- emoji 后常跟变体选择符 U+FE0F，替换正则统一用 `字符 + \uFE0F?`，避免残留不可见字符。
