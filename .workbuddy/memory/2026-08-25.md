### 关键约定 / 坑
- 业务台导航：`BusinessHome` 通过 `emit('navigate', section, filter?)` → `BusinessView.navigateTo`；`SECTIONS` 是 `as const`，`item.key` 即 `SectionKey`。
- 图标一律走 `Icon.vue` 内联 SVG（`fill=currentColor`），新增图标取 Material Design Icons（Iconify API `https://api.iconify.design/mdi.json`）。
- **沙箱 build 坑**：`rm -rf` 被 genie-safe-delete 拦截并因 trash 失败而中断 `&&` 链 → 清理临时目录改用 `mv` 移出仓库（如 `/c/Users/YangLiJuan/AppData/Local/Temp/`）。`npm run build` 的 `vite build` 清空 `dist` 时也因 trash 失败而中断 → 验证改走「直接 `node node_modules/vite/bin/vite.js build --outDir .build-xxx`」+「单独 `vue-tsc -b` 重定向到日志再 `grep error TS`」。`vue-tsc -b` 在本沙箱偶发 OOM（JS 堆 / Rust 渲染），属环境内存压力非代码问题，重试或加大 `--max-old-space-size` 即可。
- 类型检查必须看真实退出码：`vue-tsc ... | tail` 的 `$?` 是 tail 的；要 `>log 2>&1; echo EXIT=$?` 再 grep。
- 在 settings store 的 `return {}` 中避免重复暴露同名属性（曾因 `businessActiveSection` 在 state 组与 setter 组各写一次触发 `TS1117`）。
