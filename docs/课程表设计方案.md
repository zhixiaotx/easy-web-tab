# 学生工作台 · 课程表界面设计方案

> 分支：`20260918-sifujiang` ｜ 目标：在不破坏现有数据模型（`StudentTimetableCell` / `studentTimetable.ts` / `studentTimetableCore.ts`）的前提下，重构课程表面板，使其**更美观、更易用、更符合学生日常使用习惯**。
> 设计基线：移动优先；复用项目既有设计 token（`--color-primary` 等）与暗色体系（`html.dark`）；WCAG 2.2 AA。

---

## 1. 设计目标

1. **一眼看清"今天上什么、现在上什么"** —— 这是学生打开课程表最高频的诉求。
2. **学科可辨识** —— 用稳定的颜色编码学科，远看就能区分"数学/语文/体育"。
3. **编辑顺手** —— 点格子即改，弹框字段贴合真实填表习惯（学科/时间/老师/教室）。
4. **多端可用** —— 手机上不全糊、可横滑且关键列常驻。
5. **无障碍** —— 键盘可达、焦点可见、对比度达标、语义化网格。

---

## 2. 现状诊断（痛点）

| 现状 | 问题 |
|---|---|
| 所有已排课格子都是同一种蓝 | 无法快速区分学科，扫视效率低 |
| 没有"今天/当前节次"高亮 | 学生每次都要自己找今天那一列，心算现在第几节 |
| `weeks`（学周数）字段只显示在 meta | 数据能力闲置，单周视图无法体现"第几周" |
| 格子只显示 学科+老师+时间 | 教室（room）信息有存但没展示 |
| 单元格是裸 `<div @click>`，无 `role`/`tabindex` | 键盘无法操作，屏幕阅读器读不出网格 |
| 移动端 7 列 500px 强制横向滚动 | 第一列（节次）不固定，滚走后看不出是哪节 |
| 空状态仅一个"+"号 | 缺少引导，不知道点了能填 |

---

## 3. 用户习惯与典型场景

- **早晨出门前**：快速确认"今天有哪些课、第 1 节在哪间教室"。
- **课间**：瞄一眼"现在/下一节是什么"。
- **周末排课**：一次性把整周填满，按学科归类。
- **家长协同**：家长进入后只看、可导出打印。

→ 因此方案强化 **"今日速览条" + 今日列高亮 + 当前节次高亮 + 学科色图例** 四条主线。

---

## 4. 布局演进（移动优先）

```
桌面 ≥992px        平板 768–991px        手机 ≤767px
┌──────────────┐   ┌──────────────┐     ┌──────────────┐
│ 工具栏(周/教室) │   │ 工具栏(换行)  │     │ 工具栏(堆叠)  │
├──────────────┤   ├──────────────┤     ├──────────────┤
│ 今日速览条     │   │ 今日速览条    │     │ 今日速览条(横滑)│
├──────────────┤   ├──────────────┤     ├──────────────┤
│ 图例 chips    │   │ 图例(可收起)  │     │ 图例(横向滚动) │
├──────────────┤   ├──────────────┤     ├──────────────┤
│ 7列网格(完整) │   │ 7列横滑       │     │ 7列横滑+首列固定│
└──────────────┘   └──────────────┘     └──────────────┘
```

- 网格始终 7 列（周一~周日）× N 节次，移动端通过 `.tt-grid-scroll` 横向滚动，**首列（节次）与表头行 `position: sticky` 常驻**，避免滚走迷失。
- 今日列在移动端自动滚动进入视野（"跳到今天"按钮）。

## 5. 视觉设计系统

### 5.1 学科色板（稳定映射，按首字/设置顺序哈希分配，支持自定义学科回退中性色）

| 学科示例 | 色值 | 用途 |
|---|---|---|
| 语文 | `#ef4444` | 左色条 + 软底 + 文字 |
| 数学 | `#3b82f6` | 同上 |
| 英语 | `#f59e0b` | 同上 |
| 物理 | `#10b981` | 同上 |
| 化学 | `#8b5cf6` | 同上 |
| 生物 | `#14b8a6` | 同上 |
| 历史 | `#f97316` | 同上 |
| 地理 | `#06b6d4` | 同上 |
| 政治 | `#ec4899` | 同上 |
| 体育 | `#84cc16` | 同上 |
| 音乐 | `#a855f7` | 同上 |
| 美术 | `#eab308` | 同上 |
| 自定义 | 中性灰 `#64748b` | 回退 |

- **亮色**：格子底 = `color / 12% alpha`，左色条 = `color 100%`，学科文字 = `color`（深一档保证对比度 ≥4.5:1）。
- **暗色**：格子底 = `color / 18% alpha`，左色条 = `color 100%`，学科文字 = `color` 提亮（≥ `#f9fafb` 或对应浅色），灰色文字满足 ≥4.5:1。
- 颜色**只作辅助区分**，关键信息（学科名）始终以文字呈现，不靠颜色单通道传达（WCAG 1.4.1）。

### 5.2 字号 / 间距 / 圆角 / 动效 token

- 字号刻度（8px 基线衍生）：学科名 15px/600，时间 13px/500，老师/教室 12px/400，表头 14px/600，节次 14px/600。
- 间距：`--space-1..6` = 4/8/12/16/24/32px，统一 8 的倍数。
- 圆角：格子 8px，按钮/图例芯片 6px，弹框 10px。
- 动效：仅 `transform` / `opacity`，时长 `--anim-base 250ms`，缓动 `--ease-out`；按钮 hover 放大 `scale(1.02)`、按下 `scale(0.98)`。

## 6. 组件设计

### 6.1 工具栏（复用 `StudentToolbar` 形态）
- 左侧：标题"课程表" + 次级 meta「第 N 周 · 三年二班 · 每日 M 节」。
- 右侧：周次切换（‹ 本周 › 或下拉选周）、`导出Excel`、`配置`、`清空`。
- 周次切换：把闲置的 `weeks` 字段用起来——顶部 `‹ 第 3 周 ›`，仅作展示切换（单周课表数据）；若后续要"按周存不同课表"再扩展数据模型，本期**不破坏**现有 `schedule`。

### 6.2 今日速览条（新增，核心易用点）
- 一条横向卡片，展示"今天"的全部课程（按时间排序）为学科色芯片：学科 + 节次 + 教室。
- 标注"当前/下一节"。无课时显示空态文案"今天没有排课 🌿"（文案走中性，不加 emoji 依赖）。
- 移动端可横向滚动。

### 6.3 课程表网格
- 语义化：`role="grid"`；行 `role="row"`；单元格 `role="gridcell"` + `tabindex="0"` + 键盘 Enter/Space 打开编辑、方向键在格子间移动焦点。
- 表头行 + 首列（节次）`position: sticky`，分别 `top:0` / `left:0`，角落单元双 sticky。
- **今日列**：表头与整列加 `is-today` 浅色高亮底 + 顶部小标签"今天"。
- **当前节次**：若"今天"且当前时间在格子 `start~end` 内，该格加 `is-current` 强调（呼吸光环/加粗色条），其余同日格淡显。

### 6.4 课程单元格（cell）
- 有课：`[左色条] 学科名`（换行可断）/`HH:MM-HH:MM`/`老师·教室` 两枚小徽标（老师 👤 室 📍 用文字而非图标避免歧义；暗色下保证对比）。
- 无课：虚线边框 + 居中"+"，hover 变实线 + 主色。

### 6.5 编辑弹框（保留现有结构，优化）
- 顶部 meta「周X · 第 N 节」。
- 字段：学科（下拉 `settings.subjects` + 自定义开关，复用现有逻辑）、开始/结束时间（type=time，自动算 45min 默认值）、老师、教室（**新增展示+编辑**，现有数据已支持 `room`）。
- 底部：删除（仅在已有课时）/取消/保存；删除用危险色。

### 6.6 配置弹框（保留）
- 学周数（1–52）、每日节数（1–12）、教室/班级。提示文案保留。

### 6.7 空状态
- 整表无课时：网格区居中引导"点击任意格子添加第一节课"，并提示可从"设置→学科"预设学科。

---

## 7. 交互与微交互

- 点格子 → 编辑弹框（新增/编辑二态）；保存后 toast 反馈（复用 `useToast`）。
- hover：格子底变色 + 左色条/边框变主色；按钮 `scale(1.02)`。
- 点击：格子/按钮 `scale(0.98)` 0.15s 回弹。
- 今日列进入视野自动高亮；移动端"跳到今天"按钮平滑滚动到今日列。
- 编辑保存后用 `transform/opacity` 做格子淡入，避免布局跳动。

---

## 8. 无障碍（WCAG 2.2 AA 清单）

- [ ] 正文/网格文字对比度 ≥ 4.5:1，大字号与 UI 组件 ≥ 3:1（已在色板定义中校验）。
- [ ] 网格支持键盘：Tab 进网格、方向键移动、`Enter/Space` 编辑、`Esc` 关闭弹框。
- [ ] 焦点可见：`:focus-visible` 显式描边（项目已有 `--color-primary` 描边规范）。
- [ ] 语义化 `role=grid/gridcell` + `aria-label`（如"周一 第3节 数学 08:00-08:45"）。
- [ ] 颜色不单独承载信息：学科名始终有文字。
- [ ] 弹框 `aria-modal`、`focus` 进入并限制焦点陷阱、关闭后焦点归还触发格。

## 9. 实施建议（改动范围）

**复用（不重写）**：`studentTimetableCore.ts`（归一化/cell key/时间校验）、`studentTimetable.ts`（IDB/云同步/增删改）、`StudentToolbar`、`useToast`、设计 token 与暗色体系。
**改**：仅 `StudentTimetable.vue`（模板结构 + scoped 样式）+ 新增学科→颜色映射工具（建议放到 `studentTimetableCore.ts` 或新建 `timetableColors.ts`）。
**数据模型**：零改动。`room` 字段已存在，仅补展示；`weeks` 仅作展示切换，不改 `schedule` 结构。
**风险**：学科色映射需稳定（同一学科跨周同色），用"学科名→色"字典 + 哈希兜底自定义学科，避免随机闪烁。

## 10. 取舍与下一步
