## 一、总体判断

基础扎实、两个工作台布局高度一致、已落地 SVG 图标 / 暗色模式 / 键盘快捷键 / 骨架屏 / `prefers-reduced-motion`。
主要缺口集中在 **导航一致性、设计 Token 体系、弱文本对比度、字号层级、工作台互达性、移动优先方法论** 六处。

## 二、详细发现

### 1. 网站导航（HomeView 管理页）
- **emoji 残留**：左上 `🧰工作台 / 💰销售台`、右上 `⚙️设置 / ❓帮助` 仍用 emoji，而两个工作台已统一为 `<Icon>` SVG。视觉语言割裂。
- **两组 fixed 角标栏在窄屏互斥风险**：`≤768px` 时左上、右上工具栏都贴顶（top/left/right 各 8px），在 320–375px 屏宽下可能相互挤压，或与居中 `GlobalSearch` 重叠；`.container` 仅预留 `padding-top:70px` 给单边工具栏。
- **页面角色混杂**：站点导航（分类/标签）与应用管理（设置/同步/帮助/前台）全塞进浮动角标，缺少统一 App Bar 层级。
- **工作台之间无可见互链**：个人↔销售工作台仅 `g` 快捷键可达；用户在工作台内看不到去另一个工作台的按钮，必须退回管理页再点入口。

### 2. 移动优先布局
- 当前是「桌面优先 + `@media (max-width:768px)` 覆盖」，并非先小屏后增强的移动优先写法。功能可达，但方法学不符。
- 工作台 / 销售台移动端处理**良好**：侧栏 → 横滑菜单（`scroll-snap`）、触控目标 ≥40px、内容 `padding:12px`、桌面一屏钉满（`overflow:hidden` + `flex:1`）。
- **断点单一**（仅 768），无 576/992/1200 细化；HomeView 浮动栏未针对 320–375px 调优。
- 横滑菜单**无可见滚动提示/箭头**，小屏易误以为只显示部分项。

### 3. 配色方案
- 主色蓝 `#3b82f6` + 紫渐变、语义色（success/warning/error）齐全，现代清爽。整体良好。
- **⚠️ 硬伤 — 弱文本对比度**：`--color-text-muted:#94a3b8` 在 `#f8fafc` 上对比度 ≈ **2.4:1**，远低于 WCAG AA 4.5:1（即便按大号/UI 的 3:1 也不达标）。广泛用于提示/说明/占位文字，需加深至 `≥#64748b`。
- **⚠️ 双 Token 体系**：亮色用 `--color-*`（style.css），暗色用 `--bg-*/--text-*/--accent-*`（dark.css），组件靠 `var(--x, fallback)` 跨体系兜底。可用但脆弱、重复，易在新增组件时写错变量名。建议收敛为**一套语义 token，亮/暗两套主题各自覆盖**。
- 主色按钮白字态（云同步 pending：`#fff` on `#3b82f6`）≈ 3.8:1，仅达 UI 组件 3:1 下限。

### 4. 字体方案
- 单系统字体栈、基础 14px、行高 1.6，适合中文 UI。良好。
- **⚠️ 字号阶梯仅到 `xl=18px`**，无 ≥20px 的标题 / 大数字尺寸；页面 `h1` 仅 18px，缺少「英雄区」层级感，统计卡大数字需靠组件内联撑大。
- 无 `font-variant-numeric: tabular-nums`：记账 / 统计数字未等宽对齐。
- 无字重 token（仅组件内联 `600`）。

## 三、优先级整改清单

### P0 — 一致性 / 可达性（建议先做）
1. 导航 emoji → SVG（设置 `cog`、帮助 `question`/新增、工作台 `grid`、销售台 `store`），并补 `aria-label`。
2. 工作台 / 销售台头部增加**互链按钮**（或顶部 Tab 切换），消除仅靠 `g` 快捷键的隐蔽路径。
3. 修复弱文本对比度：`#94a3b8 → #64748b`（或更深）用于任何正文/说明文字。

### P1 — 结构 / 体系
4. 统一设计 Token 为单套语义变量（亮、暗各覆盖一份），删除 dark.css 中的并行 `--bg-*/--text-*` 命名。
5. HomeView 浮动工具栏重组为**统一 App Bar + 站点导航区**，窄屏避免重叠（如合并为顶部一行 + 汉堡或图标换行）。
6. 补充字号阶梯（20/24/32）与 `tabular-nums`；定义字重 token。

### P2 — 打磨
7. 将导航相关 CSS 改为真正移动优先（先 320 基线，再 `min-width` 渐进增强）。
8. 横滑菜单加滚动提示 / 两端渐隐。
9. 对齐 `.wb-menu-icon` 与 `.bs-menu-icon`（去掉遗留 `font-size:15px`，统一图标对齐方式）。
