# 管理页布局样式切换设计方案（经典网格 ⇄ 侧边栏）

> 设计角色：界面交互设计专家（PCXX AI Expert）
> 适用分支：`20260918-sifujiang`
> 目标：在**管理页（现有 HomeView）**上加一个**样式切换按钮**——默认保持当前"经典网格"样式不变，点击切换为"左侧菜单 + 右侧内容"的新布局；筛选 / 编辑 / 删除 / 拖拽 / 搜索等**功能一律不变**。

---

## 0. 需求澄清与定位

- **管理页本身就是导航**：现有 `HomeView` 已经是书签导航页（顶部 App Bar + 分类标签 + 搜索 + 卡片网格 + 分页）。无需新增"导航站"页面。
- **本次只做"样式切换"**：在管理页加一个布局切换控件（默认=经典，不变），切换到**侧边栏布局**——左侧分类菜单、右侧内容区，功能完全复用现有 store 与工具。
- **零数据模型改动**：100% 复用 `useSitesStore`（分类、筛选、分页、`incrementClick`）、`GlobalSearch`、`SiteModal`、`CategoryTabs` 数据源；仅改变布局呈现与少量交互组织方式。
- **默认样式 = 现状**：经典模式与原 `HomeView` 视觉一致，保证不破坏现有用户习惯。

**集成方式**：在 `HomeView` 顶部 App Bar 增加分段切换控件「▦ 经典 / ☰ 侧边栏」，同页内切换布局，**无新路由、无新页面**。

---

## 1. 设计基础（沿用项目 Token）

### 1.1 配色（沿用 + 分类强调色）
沿用 `--color-primary #3b82f6`、`--color-bg`、`--color-bg-card`、`--color-text`、`--color-text-secondary`、`--color-border`；暗色走 `html.dark`。

**分类强调色（稳定映射，仅作辅助；图标+文字+数量三重标识，满足 WCAG 不靠颜色单通道）**：

| 色名 | 浅色 fg | 暗色 fg |
|---|---|---|
| 蓝 `#2563eb` / `#60a5fa` | 靛 / 青 / 橙 / 绿 / 粉 / 紫 | 同源暗色提亮 |

> 磁贴图标底色、侧边栏分类"全部/分类"项在未选中时用中性，选中态用 primary；分类强调色用于磁贴图标底，仅视觉辅助。

### 1.2 字体与字号（8px 基线，单主字体）
- 字体：继承 `--font-family`。
- 刻度：页面/分区标题 20–22px/700–600；磁贴标题 14px/600；磁贴副文 12px；侧边栏项 14px；搜索框 15px。

### 1.3 间距 / 圆角 / 断点（移动优先）
- 间距 4/8/12/16/24；圆角磁贴 12px、侧边栏项 9px、胶囊 999px。
- 断点：320–575（双列）/ 576–767（3 列）/ 768–991（4 列）/ 992–1199（5 列）/ ≥1200（6 列，容器 1200 居中）。
- **侧边栏**：桌面 `248px` 固定 sticky；移动端（≤768px）收为**抽屉**（汉堡按钮 + 遮罩），不挤占内容宽度。

## 2. 两种布局说明（功能完全一致）

### 模式 A · 经典网格（默认，= 现状）
顶部 App Bar（工作台/销售台/学生台入口 + 主题/设置/帮助/前台 + 布局切换）→ 搜索 → 分类标签（横向）→ 卡片网格 → 底部分页。
> 即现有 `HomeView` 外观，本方案不改其视觉，仅作为切换的"默认态"。

### 模式 B · 侧边栏（新增）
```
┌──────────┬──────────────────────────────────┐
│ 🧭 导航管理 │ 🔍 搜索……   ＋新增  前台  [▦经典|☰侧边栏]│
│ ⟨        │ ───────────────────────────────  │
│ 工作区    │  全部站点 · 23 个站点              │
│ 🧰 工作台 │  ┌────┐┌────┐┌────┐┌────┐       │
│ 🏪 销售台 │  │ 🎬 ││ 🎬 ││ 🛠 ││ 🛠 │ 网格  │
│ 📝 学生台 │  └────┘└────┘└────┘└────┘       │
│ 分类      │  …（同磁贴，hover 出编辑/删除）…  │
│ 📋 全部 23│                                  │
│ 🎬 视频 4 │                                  │
│ 🛠 开发 5 │                                  │
│ 💬 社交 4 │                                  │
│ 🛒 购物 4 │                                  │
│ 📚 学习 3 │                                  │
│ 📁 其他 3 │                                  │
│ ───────  │                                  │
│ 🌙 ⚙ ❓  │                                  │
└──────────┴──────────────────────────────────┘
```
- **左菜单**：品牌区 + 工作区入口（原顶部左入口迁入）+ 分类菜单（全部 + 各分类，含图标/数量/选中高亮，点击筛选右侧）+ 底部主题/设置/帮助。
- **右内容**：顶部工具条（搜索 + 新增 + 前台 + 布局切换）→ 分区标题与计数 → 站点网格（与原磁贴一致，hover 出编辑/删除，失效角标，可拖拽）→ 底部分页。
- **联动**：左菜单选中分类 → 右侧仅显示该分类；搜索框两模式共享同一查询；切换布局保留当前筛选态。

## 3. 组件清单与状态

| 组件 | 说明 | 关键状态 |
|---|---|---|
| `LayoutSwitch` | 分段控件「经典/侧边栏」 | 当前态高亮，点击切换 `body` class |
| `Sidebar` | 左侧菜单容器（桌面 sticky / 移动抽屉） | 展开 / 收起（桌面图标条，可选）/ 移动抽屉开合 |
| `SidebarNavGroup` | 工作区入口组 | 默认 / hover |
| `SidebarCategoryMenu` | 分类菜单（全部 + 分类） | 默认 / hover / active（primary 实底） |
| `MainTopbar` | 右侧顶部工具条 | 含搜索、新增、前台、布局切换 |
| `SiteTile`（复用 `SiteCard` 视觉） | 站点磁贴 | 默认 / hover（上移+阴影+编辑删除）/ focus-visible / 失效角标 / 拖拽中 |
| 经典态 `CatTabs` / `Topbar` | 即现有 HomeView 组件 | 不变 |

## 4. 微交互（仅 transform/opacity，0.2–0.3s）

| 交互 | 参数 |
|---|---|
| 磁贴 hover | `translateY(-4px)` + `--shadow-card-hover`；编辑/删除按钮淡入 |
| 磁贴按下 | `scale(0.97)` |
| 侧边栏项 hover/active | 背景 `--color-bg-hover` → active `primary` 实底白字 |
| 布局切换 | 切换 `body.sb-mode`，无刷新；保留筛选态 |
| 移动端抽屉 | `transform: translateX` 滑入 + 遮罩淡入 |
| 搜索 | 输入即时过滤两模式网格 |
| 减少动画 | `@media (prefers-reduced-motion)` 关闭位移/缩放 |

---

## 5. 无障碍（WCAG 2.2 AA）

- 对比度：正文 ≥ 4.5:1，UI ≥ 3:1（Token 体系保证）。
- 键盘：磁贴为 `<a>`（Enter 打开）；侧边栏项 `<div role=button tabindex=0>` 可聚焦；布局切换为 `<button>`；焦点环 `--color-primary` 可见（`*:focus-visible`）。
- 语义/ARIA：侧边栏 `<aside>` + 分类组 `<nav aria-label="分类">`；内容区 `<main>`；分区标题 `<h2>`；磁贴 `aria-label="打开 {name}"`。
- 不靠颜色单通道：分类以图标+文字+数量标识。
- 触控目标 ≥ 44px；侧边栏项、磁贴均达标。
