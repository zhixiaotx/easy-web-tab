## P2 实施：统一微交互基础组件（已落地，未提交）
- 关键调研结论：`.btn-add/.btn-cancel/.btn-submit/.site-card/.modal` 等通用类**均在各组件 scoped 样式内重复定义**（WorkbenchDiet/Exercise/Ledger/Sleep/Weight/Todo、SiteCard、SiteModal 等），全局 CSS 覆盖不了（scoped 特异性更高）。因此 P2 采用「新增统一基础类 + 高频入口示范接入」，存量零回归。
- `style.css` 新增统一微交互 section（全部消费 P0 的 `--motion-*` token）：
  - `.ui-btn`（hover 抬升 + active 缩放 + disabled）、`.ui-card`（hover 边框转主色 + 阴影）、`.ui-input`（focus-visible 自定义焦点环：主色边框 3.7:1 + 淡蓝外环，满足 WCAG 2.2 焦点外观 ≥3:1；`[aria-invalid]` 转错误色）。
  - 可叠加工具类 `.hover-rise` / `.press-scale` / `.focus-ring`。
- `WorkbenchView.vue` 示范接入：`.wb-btn` hover 加 `translateY(-1px)`、新增 `:active:not(:disabled)` 按压缩放、transition 换用 motion token；`.wb-menu-item` transition 换 token + `:active` 按压缩放（菜单项不做抬升，避免侧栏/底部 Tab 割裂）。
